IMUs and Sensor Fusion

I found a 9-DoF inertial measurement unit (IMU) breakout board in my drawer. Originally, I wanted to use it for a univerity project, where the IMU detects gait cycles and an electical muscle stimulation unit stimulates the peroneus muscles at the right time during the cycle to prevent ankle sprains. Because we used another board this one ended up in my drawer.
Now lets use it! Should be easy to read out this old IMU sensor and do some sensor fusion, right?

1.1 Breadboarding and tests

Also the breakout board has lots of pins, we only have to consider four of them, 3.3V, ground, Serial Data Line (SDL) and Serial Clock Line (SCL), to establish a i2c connection and communicate with our sensor. The board has to sensing chips: The LSM303DLHC which features accelerometer and magnetometer and the L3GD20 as a gyroscope.
To get both of them working you have to install several libraries: Adafruit Unified Sensor Library, LSM303DLHC Library, L3GD20 Library and Adafruit 9DOF Library.
Using those I drew up my first sketch while peeking at adafruits github repository .

IMU_acceleration.ino
#include <Wire.h>
#include <Adafruit_Sensor.h>
#include <Adafruit_LSM303_U.h>

/* Nur den Beschleunigungssensor initialisieren */
Adafruit_LSM303_Accel_Unified accel = Adafruit_LSM303_Accel_Unified(30301);

void setup(void) {
  Serial.begin(115200);
  
  if(!accel.begin()) {
    Serial.println("Ooops, no LSM303 detected ... Check your wiring!");
    while(1);
  }
}

void loop(void) {
  sensors_event_t event;
  accel.getEvent(&event);

  // Values for X, Y and Z 
  Serial.print("Ax: "); Serial.print(event.acceleration.x);
  Serial.print(" | Ay: "); Serial.print(event.acceleration.y);
  Serial.print(" | Az: "); Serial.println(event.acceleration.z);
  
  delay(50);
}

Wonderful, it worked, I got my first acceleration data!

Unfortunateley, here my flow faltered. The gyroscope could not be detected, maybe I should have bought the original and not the cheap china knock off clone. To resolve this I scanned the I2C devices on my board. Low and behold, the I2C adress of my gyro is different from the one on the original board. The quickest fix I could think of is to go to the arduino library and change the adress there 0x6B to the one of my clone 0x69.
This however did not work. Maybe my clone uses a different chip. So the next best thing I came up was to ask chatGPT how to talk to the chip directly. Then I simply added this soultion to my code

talking_to_gyro_directly.ino
const int GYRO_ADDR = 0x69; 

void setupGyro() {
  //Begin talking to gyro
  Wire.beginTransmission(GYRO_ADDR);
  Wire.write(0x20); // CTRL_REG1
  Wire.write(0x0F); 
  Wire.endTransmission();

  // set sensitivity
  Wire.beginTransmission(GYRO_ADDR);
  Wire.write(0x23); // CTRL_REG4
  Wire.write(0x00); 
  Wire.endTransmission();
}

void getGyroEvent(sensors_event_t *event) {
  Wire.beginTransmission(GYRO_ADDR);
  Wire.write(0x28 | 0x80);
  Wire.endTransmission();
  Wire.requestFrom(GYRO_ADDR, 6);

  int16_t raw_gx = 0, raw_gy = 0, raw_gz = 0;
  if (Wire.available() >= 6) {
    raw_gx = Wire.read() | (Wire.read() << 8);
    raw_gy = Wire.read() | (Wire.read() << 8);
    raw_gz = Wire.read() | (Wire.read() << 8);
  }

  // Umrechnung in Radiant/s (rad/s) für den Adafruit-Standard
  float factor = 0.00875 * 0.01745329252; 

  event->version = 1;
  event->sensor_id = 20;
  event->type = SENSOR_TYPE_GYROSCOPE;
  event->timestamp = millis();
  
  event->gyro.x = raw_gx * factor;
  event->gyro.y = raw_gy * factor;
  event->gyro.z = raw_gz * factor;
}

And as you can see it works, I get lots of noisy lines :)
