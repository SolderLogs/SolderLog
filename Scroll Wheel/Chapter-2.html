Chapter 2: Start the testing

How to set up a basic touch sensor and code

1.1 The Simple Copper Plate Sensor

To get things started, I glued a piece of copper tape to a 3d-printed square and soldered a wire to it. I then connected the wire to D0 and a LED in series with a resistor to D1.
Next, I fired up the Arduino IDE to write my first simple test sketch. This sketch reads the touch value reported by the ESP and prints it to the serial monitor. The LED is not yet used in this sketch.

Capacitive Copper Square.ino C++ / Arduino 
            	
                	const int TOUCH_PIN = D0;

	                void setup() {
    	              Serial.begin(115200);
        	        }

            	    void loop() {
                	  int touchValue = touchRead(TOUCH_PIN);
                	  Serial.println(touchValue);
                	  delay(50);
            	    }

As shown in the picture, the touch value was around 85,000 when I touched the sensor and 25,000 when I left it alone. With these initial measurement, I wanted to use the sensor to controll the LED. Based on my first experiment, I assuemd that a threshold of 50,000 would work reliably to distinguish between a touch and no touch.

1.2 Simple LED Switch

Now lets build a switch. This next sketch turns the LED on, as long as the finger touches the coper tape.

Capacitive Copper Square.ino C++ / Arduino 
            	
					const int TOUCH_PIN = D0;
					const int LED_PIN = D1;

					const int TOUCH_THRESHOLD = 50000;

					void setup() {
					Serial.begin(115200);
					pinMode(LED_PIN, OUTPUT);
					digitalWrite(LED_PIN, LOW);
					}

					void loop() {
					int touchValue = touchRead(TOUCH_PIN);
					Serial.println(touchValue);

					if (touchValue > TOUCH_THRESHOLD) {
					digitalWrite(LED_PIN, HIGH);
					} else {
					digitalWrite(LED_PIN, LOW);
					}
					delay(50);
					}

As shown in the picture, this works quite well. Interestingly, the sensor was able to detect my finger even even when I it was approximateley one millimeter away from the copper tape, without actually touching it. It also worked when I turned the sensor around and touched the 3D-printed square instead.
